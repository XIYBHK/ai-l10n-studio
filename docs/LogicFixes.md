## 数据契约与旧文件

- 记忆库和术语库都必须包含 `revision`；记忆键为 JSON tuple `[source, context, canonicalTargetLanguage]`，术语必须包含目标 `language`。
- 两类库的进程内读写共享短时锁，更新后递增版本，同目录临时文件同步后原子替换；AI 请求不持有该锁。
- 旧格式库不迁移，遇到旧格式或损坏数据返回错误并保留原文件。已有数据应先另行备份，再按新契约重建；初次逻辑修复阶段没有改写个人库，随后用户授权的重建记录见下节。
- `tm_learned` 表示接受的确认键数，包含对已有键的更新，不表示新增唯一词条数。
- `TokenStats.cost` 是已知价格部分的估算；`unpriced_requests` 标记缺少价格的请求，不能用估算表示真实账单。
